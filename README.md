# spry_

A dark, minimal music player for Android: true black, vivid red, a little anime, a hint of memes.

- Streams from YouTube Music, imports your Spotify library, plays local files
- Synced, word-by-word lyrics
- Listen together with friends (group sessions)
- No ads, no trackers

## Download

Get the latest APK from [Releases](https://github.com/harshal0085/Spry/releases/latest).
Spry checks this page for updates, so new releases reach everyone automatically.

## Build

Requires JDK 21 and the Android SDK.

```
gradlew assembleGmsMobileArm64Release
```

Release builds are signed with a private key that is not part of this repository.
